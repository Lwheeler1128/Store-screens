TV links

Open a store's link in the TV's browser, then double-click (or use the kiosk app) for full screen.

Setting up a store TV

  1. Plug a Fire TV Stick or Android TV box into the TV.
  2. Install Fully Kiosk Browser (or any browser).
  3. Enter that store's TV link as the start page.
Links that start with 192.168… or similar only work on the same Wi-Fi as this computer. For TVs at other stores, run SHARE and paste its trycloudflare.com address into the box above, or move this to a cloud server for a permanent address.
